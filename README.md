# Portfolio

My personal portfolio website built with Rust using my own [`http_mambo`](https://github.com/promisejoseph/http-mambo) HTTP server library.

## Overview

This project serves as a real-world application of `http_mambo`, using it to handle HTTP requests and responses while the portfolio itself is built as a single-page website.

## Built With

* Rust
* HttpMambo
* Tokio
* HTML
* CSS

## Purpose

This project is also a practical test of the [`http_mambo`](https://github.com/promisejoseph/http-mambo) library outside of its example server, helping me validate its API and use it in an actual application.
